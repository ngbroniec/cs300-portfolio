# Portfolio Starter

This folder is an optional starting point for Individual Project 1: Professional Portfolio.
The instructions and rubric are in D2L.

## What Is in This Folder

- `index.html`: a page skeleton with comments that name each required section.
- `styles.css`: an empty stylesheet for your own CSS.
- `app.js`: an empty script file for your JavaScript feature.
- `404.html`: a basic "Page not found" page for you to restyle.
- `images/practice-book.svg`: an optional placeholder image. Put your own photos and screenshots in `images/` and replace it.
- `README.md`: this file, which you will replace.

## Your First 15 Minutes

1. Copy everything in this folder (not the folder itself) into your cloned `cs300-portfolio` repository folder. When asked about `README.md`, choose **Replace**.
2. In VS Code, choose **File > Open Folder** and open your repository folder.
3. Open `index.html` in a browser: right-click it in VS Code and choose **Open with Live Server**, or double-click the file. It is blank at first; that is expected.
4. Replace the comment in the introduction section with your name and one sentence about yourself, save, and refresh the browser.
5. In the **Source Control** view, type the message `Add starter files`, click **Commit**, then click **Sync Changes**.
6. Open the submission template from D2L and fill in its Plan section before you build more.

## What to Put in This README

Replace everything in this file with a short README for your site:

- Your name.
- Your live site address, such as `https://yourusername.github.io/cs300-portfolio/`.
- One or two sentences on what the site is and who it is for.
- Credits for any images, fonts, or icons you did not make: the name, where it came from (a link), and its license.

Example:

```text
# Jordan Lee: Portfolio

Live site: https://jordanlee.github.io/cs300-portfolio/

My portfolio for internship applications, showing my web and data projects.

Credits: hero photo by Ana Ruiz on Unsplash (Unsplash License); Inter font from Google Fonts (SIL Open Font License).
```

## Where Everything Else Goes

Screenshots, test results, case-study drafts, your two improvements, and your AI-use answers go in the submission template, which you export as one PDF.
Your repository holds only your site files and this README.
Your video goes only to D2L.
